# MOR brand integration

MOR (MoreOpenRepeater) — **Radio. Reimagined.**

This initial brand pass introduces the orange RF arcs and mountain emblem, MOR navigation lockup, and orange active navigation marker. Colors: navy `#0B1F2E`, orange `#FF7A00`, snow `#F5F7FA`.

Operational semantics are deliberately unchanged: blue primary actions, green RX, red TX, amber warnings. Existing light/dark theme behavior is retained. No backend behavior changes.
