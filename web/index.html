        Timing

        Core repeater timers and access control.

        Repeater or simplex node

        A simplex node is one radio on one frequency. Local users go to the links (AllStar, EchoLink, the link radio) but aren't repeated, and linked stations go out when nobody local is talking. There's no hang time, and no phone patch.

        Stuck-carrier lockout

        Interference or a stuck microphone makes the repeater time out again and again. After enough timeouts it stops repeating (IDs still go out) until the channel has been quiet. A carrier that never drops counts as another timeout every timeout period.

        Link radio

        off

        A second radio on its own sound device that links this repeater to a far station: another repeater's input, or a simplex link. Local users go out the link radio, and what it hears is transmitted here with the link courtesy tone. It never transmits over the far end, has its own timeout, and identifies with the station ID at least every ID interval while in use (47 CFR 97.119).

        CM108 GPIO pins

        The interface's spare pins, for relays, alarms and the like. Outputs are switched here, on the dashboard, or by a DTMF macro, and start off when the repeater starts. Inputs show on the dashboard, and can say something or run a macro when they turn on or off (after holding for a second). GPIO3 is PTT. GPIO5–8 exist on CM119-family chips only, and on a CM108AH GPIO2 can't be used.

        PinUseNameState

        Output schedules

        Switch an output on at a set time each week and off after the given number of minutes (0 leaves it on). Switching it off by hand keeps it off until next time, and after a restart an output that should be on comes back on.

        No output schedules. Set a pin up as an output above first.

        Home Assistant

        A Home Assistant macro calls a webhook trigger or fires an event, and your automations take it from there. Anyone who hears the digits can key them again, so give these macros a one-time code or a PIN, and keep them away from anything safety-related like locks or garage doors.

        One-time codes

        Anyone listening can repeat a DTMF code they overhear. For a macro that needs a one-time code, key the pattern and then the 6-digit code from an authenticator app (Google Authenticator, 1Password, Authy and the like). A code works once, and only for about a minute.

        Scan this with your authenticator app, or type in the key . Then enter the code the app shows to finish.

        AllStarLink

        Link the repeater to other AllStarLink nodes. The controller becomes the radio of a node in the AllStarLink (ASL3) install beside it: what it repeats goes out over the node's links, and linked stations are transmitted here. See the setup guide.

        Node

        Loading…

        This changes the node's rxchannel, duplex and hang time in rpt.conf, turns on Asterisk's USRP channel, turns off the SimpleUSB and USBRadio drivers if no node needs them (they'd take the controller's sound card), and restarts Asterisk, which drops any links for a few seconds. Each line it changes is marked, and Stop using this node puts them back. Copies of the files from before each change are kept in the data folder's asterisk-backups.

        Favorite nodes

        One-click buttons on the dashboard's Links card. Callsigns come from AllStarLink's node list, which is downloaded once a day. EchoLink nodes are 3 and the EchoLink number padded to six digits (3009999 for 9999).

        NodeNameMonitor only

        No favorites yet.

        Scheduled links

        Link a node at a set time each week, such as a net's hub, and drop the link after the given number of minutes (0 keeps it until someone disconnects it). A node that was already linked is left alone, and disconnecting a scheduled link keeps it down until next time.

        No scheduled links.

        EchoLink

        EchoLink stations connect to the repeater's node like AllStar links. To connect to one over the air, dial *3, then 3 and its node number padded to six digits (*33009999 for node 9999). Saving writes these settings to echolink.conf, loads Asterisk's EchoLink driver and restarts Asterisk. The router has to forward UDP ports 5198 and 5199 to this machine.
